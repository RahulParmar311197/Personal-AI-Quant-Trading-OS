# Definition of Done

## Feature
- Requirement satisfied
- Acceptance criteria satisfied
- Relevant tests pass
- Error handling exists
- No secret committed
- Security implications reviewed
- Documentation/state updated
- Regression impact checked

## Trading feature
- Timestamp semantics defined
- Historical look-ahead audit completed
- Data-quality checks defined
- Deterministic behavior tested
- Backtest impact measured where applicable

## Live execution feature
- Paper-trading validation passed
- Risk gateway enforced
- Order lifecycle auditable
- Broker reconciliation implemented
- Failure/retry behavior tested
- Kill switch available
- Live enablement explicitly reviewed
