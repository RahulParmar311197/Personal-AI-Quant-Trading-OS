# V1 User Stories

US-001 As a trader/researcher, I can load historical NSE data and inspect its quality.
US-002 As a trader/researcher, I can analyze NIFTY and BANKNIFTY across multiple timeframes.
US-003 As a trader/researcher, I can inspect technical, price-action, market-structure, SMC and ICT evidence with timestamps.
US-004 As a trader/researcher, I can inspect options-derived market context when valid option data is available.
US-005 As a trader/researcher, I can run a strategy against historical data without look-ahead bias.
US-006 As a trader/researcher, I can compare backtest, walk-forward and Monte Carlo robustness results.
US-007 As a trader/researcher, I can receive LONG, SHORT or NO_TRADE decisions with explainable evidence.
US-008 As a trader/researcher, I can see when the risk engine rejects an otherwise valid strategy signal.
US-009 As a trader/researcher, I can run paper trades and reconcile simulated orders and positions.
US-010 As an operator, I can audit system health, decisions, risk events and order lifecycle events.
US-011 As an operator, I can keep live trading disabled until explicit production acceptance.
